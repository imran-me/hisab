# assets/banks — institution logos

Self-hosted logo files for `shared/js/components/bank-logo.js`. An
institution in `shared/js/data/institutions.js` with `logo: '<file>'` shows
that file on a white tile. One with `logo: null` is drawn as a monogram in
its brand colour, which is the fallback for anything not here.

Every file lists its source and licence below. A logo is a trademark of its
owner; it is shown only to identify the owner's own account at that
institution, and a file whose source or licence is unclear is not added.
